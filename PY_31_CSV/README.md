# 📊 Анализ произвольного CSV-файла с табличными данными

Приложение для анализа табличных данных (CSV файлов) с возможностью визуализации, статистического анализа и корреляционного анализа. При разработке приложения использовался пакет Streamlit.

---

### Описание

Программа предназначена для быстрого и удобного анализа CSV файлов без необходимости написания кода. Она автоматически определяет типы данных (числовые, категориальные, даты) и предоставляет интерактивный интерфейс для исследования данных.

#### Основные алгоритмы и возможности:

1. **Автоматическое распознавание типов данных**
   - Числовые столбцы (int, float)
   - Категориальные (текстовые) столбцы
   - Даты и время (поддержка форматов: ISO 8601, YYYYMMDD, DD/MM/YYYY и другие)

2. **Статистический анализ**
   - Среднее арифметическое
   - Медиана: центральное значение упорядоченного ряда
   - Стандартное отклонение
   - Квартили (25%, 75%), минимум, максимум

3. **Корреляционный анализ**
   - Коэффициент корреляции Пирсона
   - Визуализация матрицы корреляций в виде тепловой карты
   - Выявление сильных положительных и отрицательных связей между переменными

4. **Визуализация данных**
   - Линейные графики для временных рядов
   - Диаграммы рассеяния для выявления зависимостей
   - Столбчатые диаграммы для категориальных данных
   - Коробчатая диаграмма для анализа распределения
   - Гистограммы с линиями среднего и медианы

#### Пример работы приложения:

Загрузка CSV → Определение типов → Выбор столбцов →
→ Статистический анализ → Построение графиков →
→ Корреляционный анализ → Экспорт результатов

---

### Запуск

#### Требования:
- Python 3.8 или выше
- pip (менеджер пакетов Python)

#### Запуск в терминале
streamlit run app.py

##### После запуска:
Откроется браузер с приложением (обычно http://localhost:8501)
В боковой панели нажмите "Загрузите CSV файл"
Выберите CSV файл для анализа
Используйте вкладки для исследования данных:

Данные - просмотр таблицы и информации о пропусках

Статистика - анализ числовых столбцов

Графики - визуализация зависимостей

Корреляции - анализ связей между переменными
