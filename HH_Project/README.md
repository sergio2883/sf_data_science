## Описание проекта
Данный проект посвящён анализу данных о соискателях с использованием набора данных, содержащего информацию о резюме пользователей с платформы [HeadHunter](https://hh.ru). 
Цель исследования: компания HeadHunter хочет построить модель, которая бы автоматически определяла примерный уровень заработной платы, подходящей пользователю, исходя из информации, которую он указал о себе. По результам выполнения каждого пункта исследования проведен анализ и сделаны выводы.
